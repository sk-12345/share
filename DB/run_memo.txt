# このファイルでは、実行するSQLファイルを指定します。
# "MODE" で実行方法を選び、必要に応じて "ARG" で詳細な指定をします。
#
# ==================================================

# 実行モードの種類
# MODE=all       : DB, TABLE, VALES フォルダ内のすべてのSQLファイルを順番に実行
# MODE=folder    : 特定のフォルダ内のSQLファイルを実行（ARGで指定）
# MODE=file      : 指定した1ファイルを実行（ARGで指定）
# MODE=pattern   : ワイルドカード（*）を使って複数のSQLファイルを実行（ARGで指定）
# MODE=path      : 絶対パスで指定した1ファイルを実行（ARGでフルパス指定）
#
# 各モードの使い方は以下の通りです：
#
# 例1: "all" モード（すべてのフォルダ内SQLファイルを実行）
#   MODE=all
#   ARG=
#
# 例2: "folder" モード（指定したフォルダ内のSQLファイルを実行）
#   MODE=folder
#   ARG=DB
#   ※"DB" フォルダ内のSQLファイルを実行します。
#
# 例3: "file" モード（指定した1ファイルを実行）
#   MODE=file
#   ARG=CREATE_events.txt
#   ※sql配下のCREATE_events.txtを実行します。
#
# 例4: "pattern" モード（ワイルドカードで複数のSQLファイルを実行）
#   MODE=pattern
#   ARG=TABLE\CREATE_*.txt
#   ※"TABLE" フォルダ内の "CREATE_" で始まるすべてのSQLファイルを実行します。
#
# 例5: "path" モード（絶対パスで指定したSQLファイルを実行）
#   MODE=path
#   ARG=C:\path\to\sql\custom_query.sql
#   ※指定した絶対パスのSQLファイルを実行します。
#
# ==================================================


MODE=all
ARG=
